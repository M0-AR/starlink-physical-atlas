The one-sentence version: a public, time-stamped catalog gives mean orbital elements; those elements resolve into shells and planes; the geometry changes over time; the changes support some service claims and not others; a claim ledger keeps the difference visible.

How to use this page

Start at Explorer if the terms are new. Read the definition, then the “why it matters” line. Follow one or two links, but do not try to memorize the graph. Move up a level when the definitions feel obvious. The game is the same path with feedback.
