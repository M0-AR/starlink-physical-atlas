# Validation

This document records the checks behind the atlas.  It is deliberately
separate from the paper-style summary in [`README.md`](../README.md): the
README states the results, while this file states what was tested, what was
not, and how a reviewer can reproduce each check.

All numbers below are generated by the pipeline and stored in
`results/metrics.json` or `results/tables/`.  The commands assume the pinned
environment described in the README.

## 1. Frozen inputs

The study is pinned to ten files recorded in `data/manifest.json`: three
processed snapshots, the SATCAT extract, the TLE history panel, four raw
snapshots, and the active-catalog extract.  Each entry records a SHA256 digest,
byte count, source URL where applicable, and license.

| Input | Rows | Epoch / span | License |
|---|---:|---|---|
| `nov2026` Starlink GP | 11,198 | 2026-11-19 to 2026-11-23 | CelesTrak public data |
| `apr2026` Starlink snapshot | 10,119 | 2026-03-27 to 2026-04-03 | CC BY-SA 4.0 |
| `apr2025` Starlink snapshot | 7,153 | 2025-03-27 to 2025-04-11 | MIT |
| SATCAT extract | 11,198 | launch dates 2019-11-11 to 2026-11-13 | CelesTrak public data |
| Active catalog | 16,904 | 2026-11-23 | CelesTrak public data |
| TLE history panel | 20,113 TLEs, 27 satellites | 2024-01-01 to 2025-06-01 | Kaggle, MIT |

`make verify` recomputes every SHA256 and aborts on a mismatch.  The check is
intentionally independent of the Python analysis code, so a changed input
cannot silently change a result.

## 3. Mean-element geometry

TLE mean motion is converted to a circular Keplerian radius and compared with
the SATCAT apogee/perigee midpoint for every matched Starlink object.

| Check | Result |
|---|---|
| Matched objects | 11,198 |
| Median absolute difference | 0.15 km |
| p95 absolute difference | 1.00 km |
| p99 absolute difference | 3.18 km |
| Maximum absolute difference | 38.07 km |

The median and p95 support the use of mean elements for shell detection at the
2 km scale.  The tail is not ignored: it contains eccentric or maneuvering
objects where a circular approximation is weakest.  The atlas does not use the
maximum as a precision claim.

| p05 / p95 altitude | 354.2 / 483.1 km |
| Median circular speed | 27,474 km/h |
| Median period | 93.91 min |

## 4. J2 nodal regression

A 27-satellite panel with 20,113 TLEs is propagated through time.  RAAN is
unwrapped and fitted against time; the fitted slope is compared with the
standard J2 nodal-regression prediction at the satellite's mean inclination and
altitude.

| Check | Result |
|---|---|
| Panel size | 27 satellites |
| Panel span | 2024-01-01 to 2025-06-01 |
| Median absolute relative error | 0.066% |
| p95 absolute relative error | 0.47% |
| Maximum absolute relative error | 0.915% |
| Median residual standard deviation | 0.003 deg |
| p95 residual standard deviation | 2.233 deg |
| Maximum residual standard deviation | 2.282 deg |

The residual distribution is bimodal.  A clean secular J2 drift explains one
mode; the other contains discontinuities consistent with plane changes or
orbit-control campaigns.  The fit therefore supports J2 as a first-order
geometry model, not as a complete force model.

## 5. Population identities

Snapshots are matched by normalized Starlink name because the Kaggle tables do
not carry NORAD catalog numbers.  For each pair the following identities are
checked:

```
matched + missing = earlier population
matched + new     = later population
```

| Period | Earlier | Matched | Missing | New | Later | Months |
|---|---:|---:|---:|---:|---:|---:|
| Apr 2025 -> Apr 2026 | 7,153 | 6,661 | 492 | 3,458 | 10,119 | 11.71 |
| Apr 2026 -> Nov 2026 | 10,119 | 9,761 | 358 | 1,437 | 11,198 | 7.69 |

Both identities hold exactly.  "Missing" means absent from the later snapshot,
not confirmed decayed: the SATCAT extract contains only on-orbit objects.  Name
matching can also create a false missing/new pair if an object is renamed; the
result is reported as catalog attrition, not as a survival measurement.

## 6. Shell and plane stability

Shell detection uses a 2 km altitude histogram, a 25-object peak minimum, and a
+/-8 km assignment window.  It resolves 11 shells across 5 inclination
families, assigns 10,325 of 11,198 objects (92.20%), and leaves 873 unassigned.

Plane counts are read from RAAN groups after J2 rectification.  The primary
threshold is 0.2 deg.  The sensitivity table
(`results/tables/anatomy_stability_nov2026.csv`) shows the following group
counts for the four largest shells:

| Shell | 0.2 deg | 0.3 deg | 0.5 deg | 1.0 deg |
|---|---:|---:|---:|---:|
| 43.0 / 483 km | 92 | 93 | 93 | 93 |
| 53.1 / 463 km | 124 | 123 | 125 | 116 |
| 70.0 / 475 km | 23 | 23 | 23 | 23 |
| 97.4 / 465 km | 62 | 62 | 62 | 40 |

The counts are stable across the 0.2-0.5 deg range for all four shells; the
97.4 deg shell merges at 1.0 deg.  At 0.05 deg the smallest groups fall below
the 10-object floor in the 351/359 km rings, and the main shells over-split
(100 and 122 groups), so 0.05 deg is not used.  These are effective RAAN
clusters, not design Walker numbers.  Mean-anomaly and twin diagnostics are
reported with a caveat because a 0.2 deg threshold can merge two physical
planes.

## 7. Service and dynamics consistency

The service simulation uses ten sites, 5,760 steps of 15 s, a 25 deg elevation
mask, and 9,938 satellites between 400 and 600 km.  It records zero SGP4
propagation errors.

| Check | Result |
|---|---|
| Median visible satellites (p50) | 55.0 |
| Visible range | 21-65 |
| Median handover interval (p50) | 30.0 s |
| Handover p50 range | 15-30 s |
| Median handover interval (p90) | 45.0 s |
| Median RTT lower bound | 6.19 ms |
| Median RTT upper bound | 6.27 ms |
| Median Doppler p95 | 233.6 kHz |
| Median Doppler-rate p95 | 4.12 kHz/s |
| Sites with rate p95 > 5 kHz/s | 0 |

The dynamics panel finds 510 discrete orbit-control steps across 15 satellites
(448 raises, 62 lowers).  The linearized decay indicators are:

| Family | Median altitude rate | Implied linear lifetime |
|---|---:|---:|
| 30.5 deg | -0.285 km/day | 3.23 years |
| 43.0 deg | -0.010 km/day | 131.4 years |
| 53.1 deg | -0.044 km/day | 28.7 years |
| 70.0 deg | -0.034 km/day | 37.8 years |
| 97.4 deg | -0.041 km/day | 31.4 years |

The implied lifetime is a scale from a linearized `ndot` model, not a
propagated lifetime and not a solar-cycle prediction.

## 9. Commands

```bash
make verify      # manifest hashes, README render, claim count, pytest
make test        # pytest only
make reproduce   # regenerate tables, metrics, figures, claims, README
```

`make verify` is the fast check.  `make reproduce` is the full check; the
service simulation dominates the runtime (about 75 s on the reference
machine).  The frozen inputs are already in `data/raw/`, so neither command
needs network access.

## 10. What this validation does not establish

- It does not confirm the decay of individual missing objects.
- It does not validate operational latency, gateway routing, beam scheduling,
  or network load.
- It does not estimate covariance, collision probability, or maneuver intent.
- It does not resolve design Walker numbers from effective RAAN clusters.
- It does not independently verify spacecraft mass, thrusters, laser
  terminals, launch-vehicle type, or operator maneuver totals.

Those limits are expanded in [`LIMITATIONS.md`](LIMITATIONS.md).
